# Security Policy

## Scope

GamUX is experimental software and is not currently recommended for sensitive or production systems.

## Reporting vulnerabilities

Do not publish passwords, access tokens, private keys or personal information in issue reports.

When a private reporting channel is available, use it to report security-sensitive problems.

## Development security rules

- Never store credentials in the repository.
- Do not commit Steam session tokens or passwords.
- Verify downloaded source code and release checksums.
- Preserve upstream security updates.
- Document privileged operations.
- Review scripts before executing them as administrator or root.
